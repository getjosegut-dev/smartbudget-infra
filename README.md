# Infraestructura de operaciones

Este repositorio contiene **únicamente** definiciones de tareas programadas de
GitHub Actions: respaldo de base de datos y chequeos de disponibilidad de
servicios.

No contiene código de aplicación, definiciones de datos, documentación de
producto ni credenciales. Todos los valores sensibles se inyectan como
`secrets` en tiempo de ejecución.

Los archivos se generan desde un repositorio privado y no se editan acá.
